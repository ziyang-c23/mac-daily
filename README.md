# MacDaily

[GitHub](https://github.com/ziyang-c23/mac-daily) · [v1.0 下载](https://github.com/ziyang-c23/mac-daily/releases/tag/v1.0)

简体中文 · [English](README.en.md)

MacDaily 是统一基本日常软件需求的个人 macOS 工具：把常用操作放在简洁入口，保持原生、按需运行和轻量化。

当前交付为 **v1.0**，提供简体中文和English界面，包含触控板手势、鼠标增强、窗口分屏、状态仪表盘、快捷面板、菜单栏收纳与按需空间检查。固定应用提供常用入口，Raycast 继续承担应用搜索和文件检索。

应用管理提供应用清单、关联文件卸载预览、残留扫描和用户启动代理管理。[使用说明](docs/applications.md)。

在「设置 → 语言」选择跟随系统、简体中文或English，点击「重新打开应用」后统一生效。语言选择保存在应用偏好中，手势、快捷键与规则标识保持原值。

## 构建与运行

需要 Apple Silicon Mac、macOS 14 或更新版本，以及 Swift 6 命令行工具。

```sh
./scripts/test.sh
./scripts/build.sh
ditto dist/MacDaily.app /Applications/MacDaily.app
open /Applications/MacDaily.app
```

应用位于 `dist/MacDaily.app`。构建缓存和测试样本全部位于被忽略的 `tmp/`。默认是本地 ad-hoc 签名，没有 Apple 公证；可设置 `MACDAILY_SIGN_IDENTITY` 使用自己的签名身份。改变签名后可能需要在系统设置中重新授权。

## 概览与快捷功能

左键点击菜单栏图标，打开双列状态卡片、固定应用和快捷功能；「收纳」保留独立页签。点击右上角编辑，可增删和排序；主窗口「概览」展示更大的曲线。CPU、GPU、内存、磁盘、网络和电池默认显示，温度可另行启用。

快捷功能包括定时保持唤醒／亮屏、深浅色、锁屏、桌面与Dock显示、屏幕／键盘清洁，以及已有工具与系统设置入口。查看期间每2秒采样，关闭后按菜单栏网速需求决定是否仅采集网络。[完整使用说明](docs/dashboard.md)。

## 触控板

独立页面提供手势映射、系统配置路径和实时触点试用。推荐预设含三指中键与标签页切换、窗口排列、四指面板、Control＋Option四角分屏，以及Option标题栏双指方向操作。首次关闭，选择预设后启用；原生三指冲突按规则显示。[触控板说明](docs/trackpad.md)。

## 鼠标

滚动、指针、按键与手势、应用例外分别设置。支持平滑、双轴反向、指针速度和加速，中键／侧键快捷键、按钮加滚轮及八方向手势。鼠标规则现在可以选择直接执行窗口布局。

首次运行保持暂停；平滑和垂直反向的设置默认开启，指针接管和按钮／手势预设默认关闭。显式启用后，下次启动才尝试恢复。BetterAndBetter 等工具运行时，鼠标增强保持暂停。未知来源和触控板连续滚动保持原样。

## 手势怎么用

在「鼠标 → 按键与手势」分别设置右键、中键和侧键。八方向图可直接编辑动作；按钮加滚轮独立配置，显示各组已启用数量。全部关闭时显示“没有启用的规则”。

按住对应按钮，移动到指定方向再松开，默认触发距离36 pt。识别结果与动作执行反馈分别显示。支持快捷键、窗口布局、最小化与恢复、全屏、亮度和现有快捷功能。

“从 BetterAndBetter 读取设置”提供可编辑迁移列表；选择条目并决定导入后启用右键或中键，保留未涉及的规则。应用无法直接读取受保护配置时，可使用“选择 BetterAndBetter 配置文件”。

“识别练习”仅在局部画布模拟；“真实鼠标检查”走正式设备识别及输入链，显示设备归属、位移、匹配规则与本次次数，不执行动作。[完整鼠标说明](docs/mouse.md)。

## 窗口

在独立「窗口」页面开启拖拽吸附：

- 左右边缘：半屏；四角：四分屏；顶部：填满当前屏幕可用区域。
- 底部：三分屏，沿底边移动到相邻区域可扩展到三分之二。
- 松手前显示布局预览，Escape 取消；仅确认窗口实际移动后才吸附，不处理拖文件或选中文本。
- 支持布局按钮、居中、还原、上一／下一显示器。布局按钮操作上一个外部窗口；也可打开专用练习窗口试用。练习目标固定到独立临时进程的窗口，切换应用或关闭练习窗口都不会回退到工作窗口，需显式结束练习。
- 可以调节间距、预览和拖离时恢复原尺寸；「不参与拖拽的应用」只影响自动吸附，不影响主动布局动作。

「激活方式」可选默认边缘或自定义激活区域。「自定义激活区域」将触发位置和目标布局分开：横屏、竖屏分别编辑；拖动蓝色区域移动，拖右下角调整大小，也可输入百分比。区域可以启停、增删、调整优先级，同一个布局可绑定多个区域。重叠时列表靠前的启用区域优先，区域外不吸附。

目标可选现有布局或自定义窗口位置。编辑先保存在草稿中，点保存才应用，取消不改变配置；可恢复推荐区域。拖动实际窗口时可显示激活区域提示。升级后继续使用原来的默认边缘方式，不自动切换到自定义。

窗口控制独立于鼠标增强，BetterAndBetter 的鼠标冲突不会阻止窗口模块。但不要同时启用多个工具的拖拽吸附。填满屏幕不会进入 macOS 全屏 Space；非标准窗口、全屏窗口或有最小尺寸限制的窗口会报告限制。

先在「设置」中为 MacDaily 授予辅助功能权限；无需屏幕录制、管理员组件或修改系统保护。若系统不允许创建监听，界面会报告，不降级为隐藏的权限绕过。

## 菜单栏

日常运行入口为 `/Applications/MacDaily.app`。左键打开概览和收纳页签，右键打开鼠标暂停、窗口排列、设置及退出菜单。「菜单栏」页面启用管理后，可在收纳页签访问隐藏项目。

在「菜单栏」控制面板中，把图标拖到“收纳”或“常显”分组，或点击每项的“移到收纳／常显”按钮；组内可拖动排序，也可用上移／下移按钮。设置直接同步到系统菜单栏，平时只保留MacDaily入口。

聚合面板使用应用图标与项目名称，支持横向滚动、外部点击和Escape关闭。点击项目先展开原菜单栏，再打开项目的原生菜单。原位展开默认5秒后收起，可选择10、15、30秒或保持展开；原菜单打开时暂停计时。

菜单栏管理使用辅助功能权限，首次默认关闭，目标为macOS27。关闭管理会移除MacDaily自己的分隔项，展开原图标。详见[菜单栏说明](docs/menu-bar.md)。

## 空间

打开「空间」只读取磁盘容量，点击扫描才开始遍历。默认以启动磁盘为入口，也可选择本地外置卷和文件夹；网络卷暂不支持。无完全磁盘访问权限时仍可查看可访问的范围，界面明确报告排除、失败和未完成的扫描范围。

- 概览：更大的矩形面积图与目录列表联动，可拖动中间的“调整地图大小”条分配空间；“放大查看”提供独立大幅地图，并保留目录导航。支持逐层进入、Quick Look预览、在Finder显示、复制路径或忽略。
- 大文件：默认100MB门槛，支持大小、类型、路径和修改时间筛选。大文件不自动视为垃圾。
- 重复文件：默认比较文稿、下载，可添加目录并指定优先保留目录。单独启动后才读取文件内容，按大小、分段、SHA-256和字节比较确认；每组至少保留一份。
- 缓存整理：内置规则识别应用用户缓存、已识别应用30天前旧日志、Xcode DerivedData、pip与npm缓存。uv、pnpm仅分析，不直接清理；模型、数据集、虚拟环境和项目产物不自动列为缓存。

选择项目后进入共同的待整理预览，核对路径、原因和大小，再移入系统废纸篓。默认不勾选、不永久删除、不自动清空废纸篓；项目变化、相关程序使用缓存、卷离线和权限不足会跳过或报告失败。部分成功逐项显示。

文件大小与磁盘占用估算分别显示，硬链接去重；APFS克隆共享块、快照和系统管理占用不能据此精确推算可释放空间。移入废纸篓的大小不等于已经释放的空间。

空间模块无后台定时扫描、遥测或管理员组件，扫描结果与待整理清单不持久保存。更多规则与限制见[空间模块说明](docs/storage.md)。

## 配置和迁移

配置保存在 `~/Library/Application Support/MacDaily`，不记录日常输入。可用 `MACDAILY_DATA_DIR` 指定隔离目录。

v1.0 使用配置 schema 9，支持读取 schema 1至8。保留鼠标、窗口、空间、菜单栏、仪表盘和触控板设置，增加应用扫描目录、忽略项与列表偏好；首次保存升级格式前保留对应的 `configuration.schemaN-backup.json`。回退旧版时使用对应备份。导入后鼠标、拖拽吸附、菜单栏收纳和触控板增强保持关闭。语言选择单独保存在应用偏好中。

```sh
# 只读诊断，不启用监听或修改指针
./dist/MacDaily.app/Contents/MacOS/MacDaily --diagnostics
# 只读检查迁移结果，不覆盖配置
./dist/MacDaily.app/Contents/MacOS/MacDaily --check-config /path/to/configuration.json
```
