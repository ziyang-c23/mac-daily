# 鼠标手势

在“鼠标 → 按键与手势”分别配置右键、中键和侧键。右键与中键各有点击、八方向及按住按钮加滚轮设置；分组启停互相独立。

## 设置动作

点击方向图中的箭头，选择快捷键、窗口布局、系统动作或 MacDaily 快捷功能。按住对应按钮，移动到方向，再松手执行。默认触发距离为 36 pt，可调节；到达距离后显示待执行动作。

未形成手势的普通点击和拖动按原生方式处理。滚轮组合执行后，松开按钮不再追加点击。快捷键显示“已发送”，窗口和系统动作另行报告执行结果。

## 读取 BetterAndBetter 设置

“从 BetterAndBetter 读取设置”读取本机保存的普通鼠标规则。迁移列表展示原手势、动作和可编辑的对应规则，应用所选项时仅更新相同按钮、触发方式与修饰键的规则。右键和中键可分别选择是否启用。

应用无法直接读取受保护配置时，点击“选择 BetterAndBetter 配置文件”，通过原生文件选择器打开对应文件。

支持四向、斜向、滚轮及其快捷键动作，也支持最小化、恢复最小化、全屏和亮度动作。字母、自定义轨迹和按钮间组合列明未导入原因。原文件中的左右方向不交换，动作按实际保存的键码和修饰键迁移。

恢复最小化针对该应用最近由 MacDaily 最小化的窗口。系统导航快捷键按 macOS 当前配置发送；相关设置位于“系统设置 → 键盘 → 键盘快捷键 → 调度中心”。

## 检查识别和执行

- **识别练习**：局部画布模拟，只检查方向和距离。
- **真实鼠标检查**：使用正式设备识别和输入适配层，临时显示按下、移动、松开、设备归属及规则匹配，只识别、不执行动作。

运行状态、已启用规则数、识别结果和执行结果分别显示。规则全部关闭时，页面显示“没有启用的规则”。设备未识别或权限未生效时，按页面给出的当前状态处理。

配置 schema 9 保留旧鼠标、触控板和其他模块设置，首次保存前备份旧格式。输入检查只保留界面当前状态。
