# 概览与快捷面板

点击菜单栏 MacDaily 打开概览，右键打开鼠标、窗口和退出菜单。「收纳」页签访问已收纳的菜单栏项目；概览与收纳开关独立。

## 编辑面板

右上角「编辑面板」分为仪表、快捷功能、快捷应用和偏好。「全部功能」直接打开功能管理，25项功能全部列出用途与显示开关。上移、下移调整顺序；固定应用支持直接拖动排序与右键移除，点击启动或切换应用。偏好中设置网卡、菜单栏网速、唤醒时长和Dock固定显示器。

默认显示18项常用操作，包含清洁屏幕、清洁键盘、隐藏桌面文件、屏保和Dock显示器固定。初版八项默认配置升级为扩展默认布局；自行选择过的功能组合保持原样。

主窗口「概览」使用同一份数据，提供更大的曲线。点击卡片查看详情，点击返回回到卡片。「本机信息」显示系统版本及构建号、机型、序列号、CPU性能／能效核心、GPU、内存、启动磁盘、物理SSD型号和SIP状态；主窗口默认展开，紧凑面板默认折叠。菜单栏面板宽400点，超过当前屏幕可用高度85%时滚动。

## 指标

| 卡片 | 内容与计算 |
|---|---|
| CPU | Mach CPU tick差值；蓝色用户与红色系统堆叠，深色背景表示闲置；全部核心合计100% |
| GPU | AGXAccelerator的Device、Renderer、Tiler利用率以蓝、红、青三层呈现；分项数值分别显示，不将叠加高度解释为总占用 |
| 内存 | Mach VM统计，显示已用、压缩、交换和系统内存压力；容量按二进制内存口径显示 |
| 磁盘 | 启动卷容量；从启动卷的APFS父链定位物理驱动，读取累计字节的差值 |
| 网络 | 单个所选接口的收发字节差值；自动模式选择联网物理接口，本地IP可在详情查看 |
| 电池 | IOPS电量、充电状态和电源来源，AppleSmartBattery健康信息 |
| 温度 | AppleSMC只读枚举CPU/GPU温度键，分别取同组均值；详情列出传感器键 |

默认显示前六张卡片。温度从编辑面板添加，未取得读数时显示「未读取到温度」。CPU／内存详情列出占用较高的十个可读取进程；进程CPU以单核100%计，与总CPU的多核归一化口径区分。

查看概览期间每2秒采样，曲线保留最近10分钟。容量每30秒刷新，电源通知更新电池数据。关闭概览后，开启菜单栏网速时仅每5秒读取网络；否则停止监控采样。扫描结果、曲线和进程列表不写入配置文件。

## 快捷功能

| 功能 | 操作 |
|---|---|
| 保持唤醒／保持亮屏 | 独立电源断言；15、30、60分钟或手动关闭，退出应用释放 |
| 深色模式 | 切换系统深浅色 |
| 锁屏／进入屏保 | 调用系统锁屏快捷操作／启动ScreenSaverEngine |
| 隐藏桌面 | 切换Finder桌面图标显示，重新加载Finder |
| 隐藏Dock／锁定Dock图标 | 切换自动隐藏／图标布局锁定，重新加载Dock |
| 固定Dock显示器 | 按选择的显示器限制其他屏幕外侧边缘唤出Dock，保持跨屏通道和窗口拖拽 |
| 自动隐藏菜单栏 | 修改系统对应偏好并重新加载Dock |
| 隐藏刘海 | 在有刘海的显示器顶部放置不拦截鼠标的黑色背景带 |
| 清洁屏幕 | 全屏纯色，左右键或按钮切换颜色，Escape或结束按钮关闭 |
| 清洁键盘 | 暂停键盘输入30秒；鼠标可点击结束，结束后恢复此前鼠标增强状态 |
| 鼠标增强／窗口排列 | 暂停鼠标增强，或打开现有窗口页面 |
| 空间整理／废纸篓 | 进入空间模块，或在Finder查看废纸篓 |
| 省电／显示器 | 显示省电状态并打开电池设置，或打开显示器设置 |
| 系统设置／活动监视器 | 打开系统应用 |
| 静音／声音设置 | 切换当前输出设备静音，或打开声音设置 |
| Wi-Fi／蓝牙设置 | 打开对应系统连接设置 |

带箭头的图标打开对应位置。开关的高亮表示开启状态；保持唤醒和保持亮屏使用独立会话。合盖工作采用系统外接显示器方式，电源设置在系统设置中调整。

配置schema6保存卡片、功能与应用顺序、网络选择和唤醒时长。升级保留已有鼠标、窗口、空间及收纳设置，首次写入前备份旧格式。
