# 触控板

简体中文 · [English](trackpad.en.md)

在独立「触控板」页面设置内建触控板手势。首次保持关闭，先选择「使用推荐预设」，再开启增强。鼠标与触控板分别启停。

## 推荐手势

| 手势 | 动作 |
|---|---|
| 三指轻点 | 中键点按 |
| 三指向左／右轻扫 | 上一个／下一个标签页（Control＋Shift＋Tab／Control＋Tab） |
| 三指向上／下轻扫 | 填满屏幕／还原当前窗口 |
| 四指轻点 | 打开 MacDaily 菜单栏面板 |
| Control＋Option＋单指轻点四角 | 对应四分屏 |
| Option＋双指在标准标题栏向左／右轻扫 | 左半屏／右半屏 |
| Option＋双指在标准标题栏向上／下轻扫 | 填满屏幕／还原该窗口 |

方向手势在松手时执行一次；达到触发距离后显示窗口预览。标题栏规则使用指针下的窗口，其他窗口规则使用手势开始时的前台窗口。标题栏按钮、标签页和工具栏控件不启动标题栏手势。

四角区域默认宽、高各20%，滑动距离默认占触控板尺寸10%，均可在页面调整。手指全部离开后开始下一次手势。应用或修饰键切换、Escape会取消当前操作。

## 配置原生手势

「系统手势」页显示当前值、建议值、完整路径与打开设置按钮。按以下分工配置：

| 路径 | 推荐值 |
|---|---|
| 系统设置 → 触控板 → 更多手势 → 轻扫切换全屏显示应用程序 | 四指左右轻扫 |
| 同页 → 调度中心 | 四指向上轻扫 |
| 同页 → App Exposé | 四指向下轻扫 |
| 触控板 → 光标与点按 → 查询与数据检测器 | 单指用力点按 |
| 系统设置 → 无障碍 → 指针控制 → 触控板选项 | 三指拖移关闭 |
| 系统设置 → 键盘 → 按下地球键时 | 保留更改输入法 |

原生设置由用户调整，MacDaily读取生效值。仍被系统占用的三指规则单独暂停，并显示具体设置项；四角、四指轻点和标题栏规则独立工作。自然滚动、缩放、旋转和双指页面浏览继续使用系统配置。

## 编辑与应用范围

每条规则可选择手势、修饰键和动作。动作支持快捷键、中键、现有窗口布局、快捷功能及MacDaily面板。应用专属规则优先于相同手势的全局规则；「应用例外」关闭指定应用的增强。

「补充推荐预设」仅加入缺少的全局规则，不替换已有自定义动作。导入配置后触控板增强保持关闭。

## 试用与练习

「试用」显示实时触点、指数量和识别结果。没有配置规则时，试用临时使用推荐预设；不保存或执行这些临时规则。当前原生手势占用的规则会显示对应冲突说明。

离开试用页或点击「结束试用」停止试用，并按正式开关状态恢复。使用「打开分屏练习窗口」可检查实际布局；练习模式沿用已有的专用窗口锁定。

正式动作需要MacDaily的辅助功能权限。多点触控回调仅在增强或试用开启时连接；休眠、暂停与退出停止回调。键盘录制、清洁键盘和鼠标手势试用期间，触控板增强暂时暂停。

## 实现与参考

TrackpadBridge动态加载系统MultitouchSupport接口并筛选内建设备；TrackpadGestureEngine识别触点序列；TrackpadRuntime协调事件过滤和生命周期；InputActionExecutor执行带有固定目标的动作。窗口预览与鼠标拖拽分别持有显示层。

原生偏好优先读取当前主机的有效全局配置。仅检查AppleMultitouchTrackpad共享plist会误读迁移遗留值；本机曾出现共享文件为四指、有效系统设置仍为三指的情况。

- [Apple触控板设置](https://support.apple.com/zh-cn/guide/mac-help/mchlp1226/mac)
- [BetterAndBetter](https://www.better365.cn/bab2.html)：分区轻点、修饰键与按应用规则。
- [Swish](https://highlyopinionated.co/swish/)：标题栏手势与布局预览。
- [BetterTouchTool](https://docs.folivora.ai/docs/trackpad-mouse/magic-mouse-trackpad/)、[Multitouch](https://multitouch.app/)：动作映射交互。
- [MiddleClick](https://github.com/artginzburg/MiddleClick)：三指中键产品行为。
- [OpenMultitouchSupport](https://github.com/Kyome22/OpenMultitouchSupport)：MIT系统接口布局参考，桥接实现独立编写。
