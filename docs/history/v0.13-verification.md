# v0.13 验证记录

环境：Apple M5、macOS 27.0.1（26A434），VXE R1 BT。正式应用位于 `/Applications/MacDaily.app`。

## 构建与自动测试

Release 构建与签名验证通过。全量 201 项测试、25 个测试组通过，7 种指针策略模拟通过；英文环境 4 项本地化测试通过。

新增验证覆盖八方向扇区及松手单次输出、typed动作优先级、设备会话归属、BetterAndBetter转换与合并、schema8→9迁移及备份。旧鼠标、窗口、触控板、应用、空间和仪表盘配置的保留测试通过。

## 实际配置与界面

本机设备枚举确认 VXE R1 BT，输入设备归属接口可用。BetterAndBetter 未运行。本机保存的普通鼠标规则共28条，其中14条为本次支持的方向、斜向和滚轮组合。

应用直接读取受保护的BetterAndBetter配置返回无权限；经原生文件选择器选择同一文件后，迁移预览正常显示。隔离应用及正式应用分别完成选定规则合并，右键8条、中键6条启用；保留未涉及的点击与侧键规则。

局部识别练习通过界面拖动显示“右上”，状态更新后弹窗保持打开。编辑及检查弹窗统一由鼠标页稳定宿主持有。最近一次真实检查汇总仅在内存保留，下一次检查重置；结束检查后增强保持暂停。

## 真实输入验证范围

用户完成过一轮右键四向及滚轮操作，随后手动关闭检查弹窗；该版本在关闭时清空计数，未取得可核对的完整结果，因此不记录为六项通过。后续用户选择自行进行实机测试。

尚未取得最终版本的VXE R1八方向、浏览器标签页、最小化恢复、全屏、亮度及蓝牙重连的完整验收结果。最终补充构建后，正式鼠标页显示辅助功能授权待刷新，增强保持暂停。自动测试和局部模拟不替代这部分验证。
