## 已修复的回归问题

- macOS 滚轮字段 setter 会联动其他字段；改为先快照，再一致写入，并累积低速分数刻度。
- 高轮询率手势合并缓存移动事件并保留位移，不再仅因事件数量提前放弃。
- 原生拖动回放保留 mouse delta；未知来源仅用于平衡已确认的鼠标会话，已识别触控板事件不清除鼠标会话记账。
- 权限撤销时停止增强并恢复所拥有的指针参数；监听禁用回调和低频权限检查均覆盖该路径。
- 首次启动保持暂停；只有显式启用后，下一次启动才尝试恢复。导入配置先暂停。

## 待实机验证

用户在本轮明确选择“暂不授权，先完成其余验证”。没有借用终端宿主权限绕过此选择来启用输入监听，也没有退出 BetterAndBetter。

授权并退出重复处理鼠标的工具后，需要实际验证：

1. VXE R1 的真实滚轮与按钮 sender ID，触控板同时使用时的隔离。
2. 平滑手感、修饰键旁路、侧键、按住滚轮、四方向手势和原生右键／拖动。
3. 指针速度与加速真实写入，以及暂停、正常退出、休眠后的实际恢复。
4. 蓝牙断开重连、系统睡眠唤醒、输入法、Raycast、Synergy 和常用应用共存。
5. 开机启动的系统注册与实际登录恢复。当前只检查入口存在、默认关闭，未执行注册。
6. 实际运行时的 CPU、内存及输入响应；应用包大小不代表运行资源占用。

## 已知边界

- 连续滚动事件（包括触控板惯性）和未知来源保持原样；只对已识别的普通鼠标离散滚轮进行增强。
- 高级指针层使用动态加载的 IOKit SPI，系统或设备不支持时会报告；不退化为修改全局设置。
- 暂停时最多保留 5 秒的释放收尾监听，仅处理已经捕获的按键释放，其余输入原样放行。正常退出不等待未来物理释放；按住按钮退出这一情况仍需实机验证。
- 正常退出支持恢复；强制终止或进程崩溃不能保证即时恢复硬件参数。此版本没有后台恢复守护进程。
- 构建部署目标为 macOS 14，当前仅在 macOS 27.0.1 / Apple Silicon 构建和启动验证，不宣称已测试所有系统版本。
