# v0.5 验证记录

日期：2026-10-28。本轮完善窗口拖拽激活区域。鼠标实体手势由用户后续自行测试，不将本轮窗口检查算作硬件手势验收。

## 参考与实现

只读检查本机 Magnet 3.0.7：触发区域与目标位置分别设置，可有多个区域，横屏与竖屏分别配置。未修改 Magnet 设置，未复制其代码、资源或个人快捷键。

MacDaily 新增自定义模式、区域编辑草稿、移动与缩放、百分比位置、区域启停及优先级、目标布局和自定义矩形。现有默认边缘模式保留，升级不自动切换。激活区相对完整显示器，目标相对屏幕可用区域；区域外保持原生拖动。

## 验证结果

| 层次 | 结果与边界 |
|---|---|
| 构建 | Apple Silicon release 构建通过；主应用及内嵌练习应用本地签名校验通过 |
| 自动测试 | 117项、10个测试组通过，另有7种指针恢复模拟场景通过 |
| 新增核心覆盖 | 重叠优先级、停用区域、无区域不回退、屏幕负坐标、横竖屏、自定义目标与间距、非法几何、旧配置迁移和备份 |
| 实际界面 | 打开v0.5编辑器，检查横屏与竖屏、移动、缩放、添加和删除、百分比输入、取消及保存 |
| 拖动修正 | 首轮发现区域跟随移动时的局部坐标漂移；改为固定画布坐标后，同一37pt拖动得到8.3%位移（两格），复测通过 |
| 草稿与保存 | 取消后位置保持原值；保存后读取配置确认生效。测试添加区域及位移均已清除，默认边缘模式保留 |
| 个人配置 | 鼠标字段、全部绑定和旧窗口字段逐项与本轮开始副本比较一致；schema2原始备份字节一致 |
| 权限与监听 | 更新启动初期旧授权未被识别，随后应用界面识别权限，窗口监听恢复运行；未操作其他应用的权限 |
| 运行时边界 | 自定义解析接入原预览和延迟提交路径，保留练习目标身份、前台应用和配置代际检查；本轮没有移动工作窗口 |

## 待验证

真实窗口拖入自定义区域并松手、多个显示器切换、区域提示层的实际拖动观感，尚未完成端到端实测。单元测试和编辑器操作不能替代这些验证。可先通过专用练习窗口检查，再用于工作窗口。

用户此前只确认两个侧键点击正常。VXE R1中键／右键全局方向手势、滚轮组合、应用动作、重连和休眠等仍待用户实测；不因本次窗口更新宣称通过。

## 迁移与回退

当前配置 schema3，支持读取1、2。首次覆盖旧格式前保留对应schema备份。现有鼠标和窗口行为不改变，默认激活方式仍为standard。旧版应用拒绝schema3，回退时使用原格式备份。

本地日志位于忽略目录 `tmp/activation-integration/`；交付为 `dist/MacDaily.app` 和 `dist/MacDaily-v0.5.zip`，未Apple公证。过往记录见[v0.4](v0.4-verification.md)、[v0.2](v0.2-verification.md)和[v0.1](v0.1-verification.md)。v0.4记录保留了早期窗口练习误作用于工作窗口、用户手动还原以及随后固定练习目标的更正。
