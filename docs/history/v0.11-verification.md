# v0.11 验证记录

日期：2026-10-29。环境：Apple M5、macOS27.0.1（26A434）。

## 构建与自动测试

- release构建、本地签名验证通过。
- 全量183项测试、21个测试组通过，7种指针策略模拟通过。
- 独立英文环境运行4项本地化测试通过：可见名称、格式参数与中文用户路径保留、中英资源键一致、配置默认名称保持规范值。

## 打包资源

正式应用和练习组件都携带独立的MacDailyCore资源包。应用主资源另含中英Localizable和InfoPlist字符串，供AppKit与原生接口使用。

直接运行打包应用的只读诊断：英文返回Mouse，中文返回鼠标；资源路径均指向应用Contents/Resources内的资源包，使用随包资源。

## 实际界面

已检查中文概览和语言设置入口；英文概览、系统信息、触控板设置、原生配置路径、空间页面、窗口页面与练习组件均显示英文。练习窗口的提示、返回按钮和原生窗口控件使用英文。

实际完成中文跟随系统→English→跟随系统的切换。重新打开后主窗口正常出现，进程更换，菜单与状态文字使用新语言。原有跟随系统偏好已恢复。

语言重开会先停止旧进程的运行模块，等待旧进程退出后使用系统正常打开路径启动。OpenWindowAction从已安装到界面的SwiftUI环境获取，菜单设置入口沿用同一动作。
