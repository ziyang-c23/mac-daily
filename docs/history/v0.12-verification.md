# v0.12 验证记录

环境：Apple M5、macOS 27.0.1（26A434），2026-10-29。

## 构建与测试

- Release 构建和应用签名验证通过，正式安装路径为 `/Applications/MacDaily.app`。
- 196 项测试、23 个测试组通过，7 种指针策略模拟通过。
- 应用模块 12 项测试覆盖：分类目录与包内 helper、多副本（含系统登记的扫描目录外副本）、App Group、精确标识与名称相近项、残留对照已登记应用、父子目录合并、退出拒绝与部分失败、取消、符号链接及版本化 Framework 大小、helper 偏好归属、更新器缓存归属。
- schema 7 → 8 的迁移、原配置备份和应用偏好持久化通过；既有模块配置保留。
- 英文环境 4 项本地化测试通过，中英资源键一致。

## 实际页面与服务

中文隔离应用检查了搜索、IINA 详情及其卸载预览。本体与独占缓存默认勾选，偏好和应用数据不选；未执行个人应用卸载。实际列表检查发现 Framework 别名会令目录枚举错误跳过相邻版本目录，已修正并增加对应回归测试；Google Chrome 本体逻辑大小随后显示为约 1.51 GB。

英文隔离应用检查了应用列表、残留入口和实际只读扫描；所有残留默认不选。补充处理已安装应用的 Squirrel 更新器缓存、包内 helper 标识及系统组偏好，减少误报；Preferences 只将 plist 作为应用偏好候选。

启动项实际读取显示用户代理、全局代理和系统守护进程，以及已启用、已加载和当前运行状态。无法读取的文件数量单独展示。使用项目内临时 plist 和自有 sleep 代理完成启用、加载、PID 运行、停用与卸载验证；样本和进程已清理，个人启动项未修改。macOS 27 的 print-disabled 同时支持 enabled/disabled 文字形式。

正式版已启动，应用页列出 38 个应用，显示 v0.12，当前运行的 MacDaily 本体不可勾选。

## 验证范围

卸载执行通过隔离样本及注入的移动／失败接口验证；真实个人文件只读取元数据。当前新签名的辅助功能授权未被系统识别，鼠标页面显示待授权，输入设备动作未重新实测。菜单栏原生排序与触控板物理验证继续参见历史记录。
