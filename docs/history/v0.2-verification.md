# v0.2 验证记录

日期：2026-10-28。当前交付扩展到鼠标驱动的窗口分屏，并将鼠标和窗口拆为独立页面。应用与空间仍为静态占位。窗口相关实现已完成构建、自动测试和未授权状态的界面检查；真实窗口吸附与 AX 写入尚待授权后的实机验证。

## 已验证

| 项目 | 证据与范围 |
|---|---|
| Release 构建 | `./scripts/build.sh` 成功，生成 arm64 原生 `dist/MacDaily.app`，版本0.2 |
| 自动测试 | `./scripts/test.sh`：74 项 Swift Testing 测试、6 个测试组通过；包含布局、边缘区域、底边扩展、配置迁移、鼠标窗口动作互斥，以及前台切换和还原基线回归 |
| 指针模拟场景 | 既有7种恢复／回滚策略测试继续通过；没有真实 HID 写入 |
| 新导航 | 实际打开 v0.2：鼠标、窗口位于“日常工具”；应用、空间位于“后续功能”，标注尚未实现；设置独立 |
| 窗口界面 | 已检查拖拽说明、布局按钮、目标提示、偏好与练习窗口入口；未授权时拖拽开关和布局操作不可用 |
| 练习窗口 | 实际打开600×380内容大小的独立练习窗口，并返回窗口设置；目标提示显示练习窗口，没有调整工作窗口 |
| 旧配置兼容 | 合成 schema1 样本保留旧鼠标值和规则，迁移后窗口默认关闭，首次保存有备份；当前本机没有保存的个人配置文件，因此没有声称迁移了真实个人配置 |
| 输入动作 | 窗口动作不会同时发送备用快捷键；拖拽排除不禁用显式鼠标窗口动作；应用切换取消未执行动作 |
| 包完整性 | 本地 ad-hoc 签名验证和 ZIP 解包后签名验证；没有 Apple 公证 |

原始日志在本地忽略目录 `tmp/windows-phase/`。这些自动测试不安装系统输入监听、不向桌面发布输入事件，也不改变真实窗口或指针属性。

## 复核后修正

- 松手后等待原生拖拽结束的延迟提交保存目标与代际；切换应用、Space、屏幕变化和取消使其失效。
- 提交前再次核对前台 PID。Cmd 拖动后台窗口保留原生行为，不显示无法提交的预览。
- 自由移动／调整尺寸后更新还原基线；连续吸附保留最初位置。
- 拉出恢复失败后取消本次吸附，不在每个拖动采样上重复写入 AX。
- 界面按钮使用明确的目标窗口，练习窗口与工作窗口不混淆；分屏例外只作用于自动拖拽。

## 待实机验证

当前独立 App 界面显示辅助功能未授权。本轮已询问是否授权并仅使用练习窗口测试；在获得授权前，未借用终端宿主权限启用窗口监听或执行 AX 调整。

尚需验证：

1. 拖动练习窗口到两侧、四角、顶部、底部，检查预览、松手吸附、底边扩展和 Escape 取消。
2. 真实窗口还原、拖离恢复、应用最小尺寸限制和多显示器坐标。
3. 文本选择、拖文件、拖标签及调整窗口尺寸不会触发吸附。
4. 鼠标按键／手势绑定窗口动作的端到端执行。
5. 权限撤销、休眠、屏幕重连和系统原生平铺共存行为。
6. v0.1 留下的真实滚轮、指针属性恢复、输入法与 Synergy 共存测试。

## 构建与兼容边界

构建目标为 macOS14 / Apple Silicon，本机构建与启动环境为 macOS27.0.1。其他系统未实测。只支持标准可调整窗口；最大化使用当前显示器可用区域，不进入 macOS 全屏 Space，不移动到未激活的其他 Space。应用的尺寸限制会通过实际读回报告。
