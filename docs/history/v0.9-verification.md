## 原生采集

直接编译实际SystemMonitorService，采集本机数据，无配置写入。以下读数来自三个连续样本，CPU与速率使用具有前后基线的后两个样本。

| 项目 | 结果 |
|---|---|
| CPU | 总占用约17.8–20.0%，用户／系统分别取得 |
| GPU | 利用率31–45%，核心数10 |
| 温度 | AppleSMC读取成功，CPU约47–48°C，GPU约46–47°C |
| 内存 | 总量34,359,738,368字节，界面按32GB显示，压力正常 |
| 启动盘 | 总量494.33GB；物理驱动读223–688KB/s、写712–822KB/s |
| 网络 | 单接口取得实际上传／下载差值 |
| 电池 | 电量98%，健康100%，读取成功 |
| 进程详情 | CPU／内存详情各返回10个可读取进程；CPU按Mach时间基准换算 |

启动盘从根挂载`disk3s1s1`沿APFS父链定位`disk0`物理驱动。温度先枚举传感器，只读取CPU／GPU对应组。

采样调度实测：可见模式2.3秒取得2次快照；停止需求后2.3秒取得0次；网络模式5.3秒取得2次，未增加曲线历史、未读取进程列表。

含温度与进程详情的单次采样耗时：首次34.1ms，后续14.6ms、16.6ms。独立探针16.67秒消耗0.08秒CPU时间，最大RSS约11.5MiB；此值为采集探针，不能替代应用整体占用。

## 应用界面与开销

正式应用已实际检查：主窗口概览、CPU／内存详情、实时进程列表、编辑面板内容、400点菜单栏概览和独立收纳页签。CPU蓝／红堆叠面积与GPU蓝／红／青分项堆叠均已检查实际呈现；本机信息显示版本、型号、序列号、4性能＋6能效核心和物理SSD型号。CPU、GPU、内存、磁盘、网络、电池显示实际数据，曲线持续更新。

系统信息独立探针九项均有值，首次读取10.2ms，缓存读取0.1ms。序列号未写入探针记录。

## 快捷功能与实际操作

独立原生探针执行实际QuickActionService：保持唤醒创建PreventUserIdleSystemSleep断言；保持亮屏创建第二个独立断言；关闭前者后亮屏断言保留；服务停止后两者全部释放。

Dock固定所用几何函数的六个场景通过：次屏外边缘限制、目标屏幕保持不变、共享边缘仍可跨屏。静音读取与原生CoreAudio属性一致，未切换输出状态。

屏幕清洁已实测进入全屏、切换到白色、Escape退出与鼠标按钮退出，白底按钮文字可读。键盘清洁已实测进入30秒倒计时、结束后恢复鼠标增强。最终构建的辅助功能已由用户刷新，已再次确认鼠标增强运行中。Dock固定监听已实测启用和关闭；跨屏边缘使用实际几何函数验证。深浅色、桌面／Dock偏好与锁屏未在本次测试中切换。配置迁移与排序测试使用项目内隔离样本；既有鼠标与窗口配置保留，默认快捷功能扩展至18项。

辅助功能授权后，菜单栏目录读取到收纳与常显项目。错误归组的坐标路径改为同一展开AX快照读取，并排除仍保留折叠宽度的边界；指定State图标进入收纳的操作未通过：操作后State仍在常显列表，读取项目数随显示器目录变化。已停止后续移动；原生菜单激活与排序作为独立未通过项保留。
